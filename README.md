# 计算模板

结构计算用的小网页，纯静态，无依赖，双击就能在浏览器里打开。计算模板离线可用；首页反馈箱读取在线 GitHub 留言。

## 首页反馈箱

- 首页模板列表下方提供反馈箱，顶部「意见与建议」可直接跳转。
- 每条留言默认折叠，显示意见正文的第一个非空内容行、发表日期、作者、回复数和讨论状态；点击展开可读完整意见及全部成员 / 管理员回复。日期统一使用北京时间。

- 点击「提出意见」进入 GitHub 反馈表单；点击留言下方「回复此留言」进入该条 Issue 的回复区。**发表、回复需要 GitHub 账号，写入在 GitHub 完成，首页不提供独立账号或匿名提交。** 提交后回到首页可自动刷新，也可点击「刷新留言」。
- 当前管理员为仓库所有者 `xiaodi-k`。账号列表位于 `feedback.js` 的 `administrators` 中，徽章依据 GitHub 返回的作者登录名显示。该列表仅控制展示，不授予 GitHub 权限；权限管理、编辑、关闭和锁定由 GitHub 执行。新增管理员需同时按实际需要设置仓库权限。普通协作者不会自动被标成管理员。
- 关闭的留言仍保留对话，标记为「已关闭」，不据此声称需求已经解决；锁定的对话不显示普通回复入口。管理员可通过「查看原文 / 管理」处理。

## 目录规则

```
calc-templates/
├── index.html      # 首页，列出所有模板
├── README.md
└── <模板名>.html   # 每个计算模板一个文件，直接放在这一层
```

## 加一份模板

1. 新建一个 `xxx.html`，写你的计算页面；
2. 打开 `index.html`，在 `calcs` 数组里加一条：

   ```js
   {
     name: "显示的名字",
     file: "xxx.html",
     note: "一行备注，可留空",
     ver:  "1.1",          // 首页卡片右上角显示的版本号
     date: "2026-10-21"     // 最后更新日期
   }
   ```

首页会自己渲染出卡片：左侧是序号（按 `calcs` 顺序），右上角是版本号，下方是最后更新日期。
数组为空时首页显示空状态提示，不会预置任何示例内容。

## 版本号规则

首页显示的版本号由「建立以来的改动次数」推出来：

```
1.<累计版本次数>                 没有图示类改动时
1.<累计版本次数>.<图示改动次数>    有图示类改动时补第三段
```

- **建立那一次算第 1 版**，之后每改动一次 +1；
- 统计口径是该文件在 git 里**出现过的不同内容版本数**，所以内容没变的提交
  （比如误删后又原样恢复）不会被误算成一次改动；
- **图示改动次数** = 计入版本的提交里属于图示类（图样、支座符号、示意图…）的次数，
  一眼能看出这个模板是不是主要在调图；
- **只改版本号、时间戳这类元信息不计次数**。

例：`立柱（竖梃）承载力计算` 累计 5 个内容版本，其中 4 次是图示改动
（支座三角旋转 90°、支座符号区分 PIN 与滑动、PIN 移到最下方、倾角 α 图随角度倾斜），
所以显示 **1.5.4**。

数字由仓库外的 `version.py` 读 git 历史算出，不靠人工计数：
默认只做比对，加 `--write` 才写回首页。脚本刻意不放进本仓库，保持这里只有静态页面。

## 约定

- 单个模板页自包含：样式和脚本写在同一个 `.html` 里，不引外部 CDN，断网也能用。
- 页面直接用 `file://` 打开即可，不需要起服务、不需要构建。
- 公式排版用模板页内置的 `tex2html()` 迷你 TeX 渲染器，不引 KaTeX / MathJax。
- 每个模板页页脚留有版本戳，形如 `版本 1.5.4 · 2026-10-21 16:28`，与首页保持一致。

## 玻璃面板：高级模式的 ASTM 选项（1.18.6）

基础模式与高级模式的 JGJ 102-2003 计算保留原有算法。高级模式新增
ASTM E1300 选项，具体依据为 E1300-16 附录 X6/X7 的独立应力分析，
不是完整 NFL 图表承载力工具，也不代表 IBC 全部设计要求均已完成。

- 输入 W 是未折减的 ASCE 7 C&C 风压，按项目指定强度用 1.0W，玻璃面板
  风挠度用 0.42W。IBC 2024 §2404.1 对竖直玻璃的比较为 0.6W；本程序
  保留用户要求的更保守 1.0W。不要直接输入已经折减的 ASD/SLS 压力再乘 0.42。
- 风的持续时间为 3 秒。大面许用应力：AN/HS/FT = 23.3/46.6/93.1 MPa，
  不按厚度分档；边缘按表 X7.1 及加工方式单独校核。HS/FT 切割边为 N/A，
  不自动代替为倒棱边。
- 可另输入同向不利的长期侧向均布压力 QL（默认 0），选择表 X4.1 的持续
  时间系数；长期值 = 3 秒许用值 × Kd。**这是线性模型采用的保守工程折减，
  X4 原文转换的是荷载承载力，并非长期应力表。尤其热处理与边缘应力需复核。**
  不再叠加 Table 1 GTF。风与长期作用按应力利用率相加。
- 厚度默认按表 4 从公称值转为最小值，也可直接输入已确认的最小厚度。
  表 4 无 15 mm 档，程序不插值或静默转换；16 mm 对应 15.09 mm。
- 四边连续简支使用 Navier 线弹性板解，含扭矩的主弯矩及边缘扫描；计算范围
  长短边比 1–10。对边简支采用单位宽度梁条带。没有沿用 JGJ 的大挠度 η。
  全幅风/长期荷载的线性挠度与有效厚度之比大于 0.5 时提示非线性复核；
  0.5 是本程序筛查阈值，不是 ASTM 限值。
- PVB/SGP 的 G 均默认 0（完全分层极限），可分别输入与实际温度及风/长期
  持续时间对应的厂家 G 数据。两片夹层用 X9.1–X9.8，每片采用自己的应力
  有效厚度。多于两片的夹层仅支持 G=0，不递归套用两片公式。
- 中空按各组刚度比例作近似分配，未套用中国外片 1.1 系数。密封腔耦合、
  气候荷载及整樘破坏概率未验证，因此中空结果标为需复核。点支承孔边分析
  不在此分支实现范围内，会阻止显示通过结论。国标的四点支承功能保留。
- 0.42W 和挠度限值分母是本项目面板设置，不能代替支承框架的挠度校核。
  中国风震组合不参与美标分支；自重沿竖直板面仅展示，不自动作为侧向压力。
  本页不覆盖雪荷载组合、抗震位移、冲击及破碎后性能。

来源核对：ASTM E1300-16 表 4、表 X4.1、X6.2、表 X7.1、X9.1–X9.8；
IBC 2024 表 1604.3 注 f、§1604.3.7、§2404.1。
标准全文未随仓库分发。ASTM 选项的版本固定在已核对的 2016 版，未声称采用 2024 版。

验证：486 组国标结果逐项对比修改前版本；美标解析条带算例、应力/持续时间
表、最小厚度、0.42 风挠度、X9 例 13（h_w≈12.558 mm，h_σ≈14.131 mm）、
Navier 级数/网格加密对比及错误输入检查。另检查规范切换、图中输入、边缘
N/A、打印样式和手机布局。验证脚本保存在开发工作区，仓库仍为自包含静态页面。

### 内片玻璃局部等效静力 FEM demo · v1.2.2

`glass-impact-demo.html` 分析普通幕墙内侧单片矩形玻璃的等效静力响应。默认
Pk=1.0 kN、γ=1.5、κ=1.0、直径 100 mm 圆形接触区、作用点在完成面以上
1100 mm，玻璃底标高另行输入。参数是演示设定，未定义上海地标或 IBC 项目荷载。

- 板宽、高 200–10000 mm；目标网格尺寸 20–500 mm。按嵌套分层要求向细网格取整，
  明示实际单元尺寸，不把大模型静默换成粗网格。10 m × 10 m、目标 20 mm 对应
  512 × 512 单元、1,052,676 个总自由度。
- 三种实际边界：四边连续简支；顶底两边简支、左右自由；四角点支承。
  简支边限制面外位移及相应切向导数；四角只限制角点面外位移，不锁定转动。
- BFS C1 矩形 Kirchhoff–Love 线弹性薄板，4 DOF/节点；4×4 Gauss 刚度积分。
  圆与单元交集采用分段角度变换积分，按真实圆面积计算压力并验证面积及合力。
- 矩阵自由 9 节点刚度模板、几何多重网格预条件共轭梯度、最粗网格 Cholesky。
  三次 Hermite 延拓和转置限制；报告真实残差、反力平衡、迭代和耗时。
  输入修改即取消旧 Worker、清空过期结果；离线运行，无服务端和 CDN。
- AN / HS / FT 强度取 JGJ 113-2015 表 4.1.9（短期荷载），按厚度区间分别显示
  中部、边缘、端面值；13–14 mm 等非表列区间不自动外推。E=72000 MPa、ν=0.22 固定，
  不再占用输入框。材料选择本身不代表安全玻璃适用性认定。
- 云图采用蓝—青—绿—黄—红的分段色带和右上角纵向色标。拖动旋转、滚轮或双指缩放、
  Shift/右键拖动平移、一键正视及复位。荷载沿玻璃法向，正视投影为点。
  尺寸、荷载、网格、有限元结果可切换；结果关闭显示原形玻璃和支承。
- 数值最大值保持每单元 5×5 采样的双表面主拉应力包络，不平滑数值峰值。
  图像用独立显示网格的三角形插值分段绘制等值线；显示插值不代替局部应力收敛。
  四角理想点支承不模拟孔洞、垫片或有限支承面，支点附近局部峰值须另行分析。
- 多档网格对比、独立圆形局部荷载 Navier 挠度对照和 JSON 导出。
  挠度/厚度>0.5 只作小挠度筛查提示，不是规范限值；不输出冲击合规结论。

验证记录：
- 三种边界均与独立带状直接求解对照，指定矩形加载基准的最大自由度差小于 1.1e-9。
- 圆形加载独立 Fourier–Bessel/Navier 对照：默认参数、目标 20 mm 网格，
  作用点挠度相对差约 0.000020%，同点主拉应力差约 0.38%。这是指定算例结果，
  不是所有输入的精度保证。
- 荷载/厚度缩放、对称性、圆荷载面积/合力/一阶矩、材料表、范围及错误输入测试通过。
- 10 m × 10 m、20 mm 目标网格，三种支承均完成；本机 Node 计算约 2.4–3.0 s，
  进程内存约 126–128 MB，实际浏览器速度取决于设备。
- 模拟 DOM/执行真实 Worker 脚本的交互测试覆盖旋转、缩放、正视、可见性、
  支承及材料切换、最大模型、收敛、旧结果取消和 JSON；实际 SVG 已渲染检查。
  未完成真实浏览器整页和跨浏览器验收，也未对新版逐工况做 RFEM 交叉验收。

模型仍限于线弹性小挠度单片玻璃；不模拟真实动态冲击、接触压痕、破碎、夹层剪切、
中空腔耦合或防坠落栏板。真实项目需结合荷载组合、非线性、连接和试验要求。
